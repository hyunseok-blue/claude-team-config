# /fusion — Opus + Codex(GPT-5.5) + Gemini 3-모델 앙상블

세 개의 최상위 모델에게 같은 질문을 던지고, 답을 교차검증·종합해 단일 결론을 낸다.
"Fusion API"라는 단일 융합 모델은 실재하지 않으므로, 이 커맨드는 **오케스트레이션(앙상블)**으로 그 효과를 낸다:
Opus(현재 세션) + Codex(`codex exec`, GPT-5.5) + Gemini(`agy --print`)를 각각 독립 호출한 뒤 Opus가 종합한다.

## 사용

```
/fusion <질문>
/fusion 파이썬 GIL이 멀티스레딩 성능에 미치는 영향은?
```

## 흐름 (메인 Claude 세션이 따라야 하는 단계)

### 0. 질문 확정
- `$ARGUMENTS` 가 질문. 비어 있으면 사용자에게 질문을 1줄로 요청하고 중단.
- 질문을 변수처럼 다룰 텍스트로 확정(`Q`). 셸 인자에 안전하게 넣기 위해 작은따옴표 escape에 유의.

### 1. Opus 초안 (현재 세션이 직접)
- 외부 모델 결과를 보기 **전에**, 현재 세션(Opus)이 질문에 대한 답 초안을 자체적으로 작성한다.
  (다른 모델 답에 끌려가지 않도록 먼저 독립적으로 생각한다.)

### 2. Codex(GPT-5.5) + Gemini 동시 호출 — 백그라운드
두 호출을 **같은 응답 블록에서 각각 `run_in_background: true`로** 띄운다(병렬). 그 다음 완료 알림을 기다린다(sleep/poll 금지).

Codex:
```bash
codex exec --skip-git-repo-check -m gpt-5.5 '<Q>' 2>&1 | tee /tmp/fusion-codex.log
```

Gemini(agy):
```bash
agy --print="<Q> — 텍스트로만 답해줘. 코드/이미지 생성 말고 설명 텍스트로." 2>&1 | tee /tmp/fusion-agy.log
```

규약(반드시 준수):
- 프롬프트는 `agy --print="..."` 값결합. 위치인자/stdin 리다이렉트 금지.
- 출력은 `| tee /tmp/fusion-*.log` (파이프는 종료 후에만 보임).
- agy 첫 호출이 "Authentication required ... timed out"(30초)이면 **동일 명령 1회 재시도**(실측상 통과).
- `timeout` 명령은 macOS에 없음 — 쓰지 말 것. 백그라운드 + 완료 알림으로 대기.

### 3. 결과 수집
- 두 백그라운드 작업 완료 알림을 받으면 `/tmp/fusion-codex.log`, `/tmp/fusion-agy.log` 를 Read.
- 각 로그에서 모델의 실제 답변 본문만 추출(진행 로그/배너는 무시).

### 4. 종합 (현재 세션이 메타-검토)
세 답(Opus 초안 / Codex / Gemini)을 비교해 단일 결론을 낸다. 출력 형식:

```
## 종합 답변
<세 모델을 교차검증해 도출한 최선의 단일 답>

## 모델별 차이점
- **합의**: 세 모델이 공통으로 말한 핵심
- **불일치/보완**: 한 모델만 짚은 포인트, 서로 어긋난 부분과 어느 쪽이 옳은지의 판단 근거
- **신뢰도 메모**: 사실 검증이 필요한 주장이 있으면 표시
```

판단 원칙: 다수결이 아니라 **근거의 질**로 판정한다. 한 모델만 맞아도 근거가 탄탄하면 그쪽을 택하고 이유를 밝힌다.

## 비용 주의
3개 모델 동시 호출이라 토큰/시간/비용이 단일 대비 3배+. 가벼운 질문에는 일반 세션을, 교차검증이 가치 있는
중요한 질문에만 `/fusion`을 쓰는 것을 권한다.
